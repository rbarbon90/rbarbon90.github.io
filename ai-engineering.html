Foco dos projetos

Arquitetura de IA com precisão, rastreabilidade e entrega

Esta área reúne projetos em que a IA generativa precisa sair do protótipo e virar fluxo de produto: APIs, bancos vetoriais, guardrails, métricas, avaliação e observabilidade.

O objetivo é mostrar maturidade técnica para lidar com custo, latência, qualidade das respostas, fontes, segurança e integração com sistemas existentes.

Projeto principal RAG

Enterprise RAG Platform

Plataforma para consulta de documentos empresariais com ingestão, chunking, embeddings, banco vetorial, reranking e respostas rastreáveis com fontes.

Problema Conhecimento interno disperso em PDFs, manuais, políticas e bases pouco pesquisáveis.
Solução Pipeline RAG com FastAPI, Qdrant, embeddings, reranking, citações e logs de avaliação.
Impacto Busca mais rápida, respostas auditáveis e caminho claro para evolução com métricas.
Python FastAPI Qdrant OpenAI Docker
Agentes LLM + Tools

AI Data Analyst

Agente analítico que interpreta perguntas, chama ferramentas, valida SQL e devolve gráficos com explicação executiva.

Diferencial Separação entre raciocínio, execução de consulta, validação e resposta final.
Entrega API com logs de decisão, exemplos de uso e limites claros para consultas seguras.
LangGraph PostgreSQL Pydantic Plotly

LLM Evaluation Framework

Framework para comparar prompts, modelos e versões de aplicação por precisão, relevância, fidelidade ao contexto, segurança e custo.

Diferencial Scorecards versionados para evitar regressão de qualidade entre mudanças.

Internal Support Agent

Assistente para atendimento interno com base de conhecimento, classificação de intenção, respostas padronizadas e escalonamento para especialistas.

Diferencial Combina RAG, roteamento de intenção e limites de resposta para reduzir alucinação.
Entrega Protótipo com fluxo conversacional, logs e painel de perguntas não respondidas.
